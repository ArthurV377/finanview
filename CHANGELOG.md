# Histórico de versões — FinanView

## Versão 1.0

- Primeira versão conteinerizada da aplicação.
- Conversão de moedas com a API Frankfurter.
- Interface para seleção e inversão das moedas.

## Versão 1.1

- Melhoria visual da lista de moedas favoritas.
- Persistência de favoritos com Supabase.
- Ajustes de responsividade na lista de favoritos.
- Imagem Docker publicada com a tag `1.1`.
- Tag `latest` atualizada para acompanhar a versão mais recente.

## Melhorias de acessibilidade

- Adicionado contorno visual para indicar o foco dos botões durante a navegação pelo teclado.
